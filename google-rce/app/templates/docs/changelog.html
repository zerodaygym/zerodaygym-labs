Changelog

Platform and documentation-portal release notes.

Portal 4.18.2

  • Sign-in: the portal now marks the flow session as permanent so a slow consent step no longer drops the in-progress flow.
  • Sign-in: consolidated the portal fleet onto a single OAuth 2.0 client so that one consent covers every developer site.
  • Search: fixed ranking for reference pages.

Portal 4.17.0

  • Removed the server-side session store. Flow state now rides in the signed session cookie, which lets any portal replica serve any callback.
  • Docs: new Authentication reference page.

Portal 4.15.4

  • Pinned oauth2client==4.1.3 after an upgrade attempt broke the Flask integration.
  • Dark theme for code samples (rolled back, see 4.15.5).
