Quickstart

Call your first Nimbus Platform endpoint.

1. Install the SDK

pip install nimbus-platform

2. Sign in to the portal

Use Sign in in the header, or hit the endpoint directly:

curl -sI 'http://localhost:13337/oauth2authorize?return_url=%2Fdocs%2Fquickstart'

The portal issues a session cookie and redirects you to the consent screen. See Authentication for what the cookie carries.

3. Make a call

from nimbus import Client

client = Client()
print(client.buckets.list(project="demo"))

4. Next steps

  • Authentication — sign-in endpoints and session layout.
